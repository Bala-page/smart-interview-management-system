# Smart Interview Management System — Client Application

Frontend single-page application built with React 18, Vite, and Redux Toolkit.

## Development Scripts

- `npm run dev`: Launch local Vite dev server at `http://localhost:5173`
- `npm run build`: Compile optimized production bundle to `dist/`
- `npm run preview`: Preview production build locally

## Technologies
- React 18
- Redux Toolkit & React-Redux
- React Router v6
- Native SVG Icons and Charts (no external CDNs)
- Pure CSS with Design Tokens (`variables.css`)
